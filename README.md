# Dreamplay1 – GitHub Pages Website

## Files
- `index.html` — homepage
- `blog/index.html` — featured blog article
- `styles.css` — shared responsive styling
- `assets/dreamplay1-logo.png` — supplied logo

## Publish with GitHub Pages
1. Create or open the GitHub repository connected to `dreamplay1.app`.
2. Upload the contents of this folder to the repository's root (not the folder itself).
3. Confirm that `index.html` is in the repository root.
4. In **Settings → Pages**, choose the correct branch (usually `main`) and `/ (root)`, then save.
5. In your domain/DNS settings, configure the custom domain as `dreamplay1.app` and follow GitHub Pages' DNS instructions.
6. Enable HTTPS after GitHub verifies the domain.

The blog will be available at `https://dreamplay1.app/blog/`.

This is a static HTML/CSS/JavaScript website. Forms, accounts, live scores, game engines and server-side features are not included.
